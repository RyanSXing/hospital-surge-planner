## Correctness blockers

| Priority | Finding and evidence | Required correction |
|---|---|---|
| P1 | `apps/web/src/api.ts:18` adds UTC days; `App.tsx:19` divides elapsed milliseconds by 86,400,000. Replay also uses `horizon * 24` and a UTC-duration fallback. The required November 1 Chicago day has 25 hours. | Use API-provided local-calendar bucket boundaries and authoritative exclusive `end_at`; select actual bucket timestamps, not elapsed-day arithmetic. Preserve 1–365 local-calendar-day semantics. |
| P1 | `Compare.tsx` renders `physical={100}` and a staffing count of 100 for `staff_existing`, 80 for every other plan, regardless of dataset, selected unit, start time or simulation. | Render computed per-plan capacity and timing from result/resource state. Never present fixture constants as evaluated results. |
| P1 | `Resources.tsx` presents all clinics as 12 physical, 8 staffed, 90-minute service and 6-hour activation, and staff as 52+7 per shift/four teams. These are fixed strings and therefore wrong after editable dataset changes or selecting a newly added clinic. | Resolve selected facility/unit policies, resource requirements and schedules from the actual dataset and selected run. |
| P1 | `components/CampusMap.tsx` uses a fixed `positions`/`names` map and fixed site descriptions. Candidate sites added through Resources are not added to these markers; edited facility coordinates/names do not drive the map. | Build geometry, markers and labels from dataset facilities and site states. Fit bounds to those facilities. |
| P1 | `model.ts` derives queue and usable capacity on the frontend, including `staffed - occupied - reserved - cleaning`, and falls back to source data when `ctx.state` is absent. | P1 | `surge_api.main.summary` picks a planning-baseline dataset independently of the latest scenario and run. Opening a stress/new-version scenario after refresh can therefore combine different dataset/scenario/run contexts. | Choose one coherent context and resolve dataset from the selected scenario/run. | P1 | `surge_api.main.comparison_value` assigns only `result['scalar_metrics']` to plan.metrics; `Compare.tsx` looks for `p.metrics.series` for the comparison chart. | Return chart time series under an agreed typed contract and display paired p10/p50/p90 differences/probability, not only one median. |

| P1 | Observed-reset handling simply swaps dataset, clears updates, truncates the remaining horizon using UTC `.days`, and has no complete coverage/reconciliation preview or duplicate-batch handling. | Validate complete snapshot/time, reconcile IDs/resources and updates, preserve local exclusive end and parent history, and integrate new waiting only after cutoff. |
| P1 | `Patients.tsx` maps a bed-grid index to the index of a filtered patient array, not an actual `slot_id`; `BedGrid` draws occupancy counts sequentially. Clicking an apparent bed can select a patient assigned elsewhere. | Render canonical slot state and exact patient allocation; preserve reserved/cleaning/blocked/capability states. |

## Shared-layer repair evidence (2026-10-17)

- Calendar-day helpers now preserve Chicago wall time over 23/25-hour days; targeted tests cover both transitions and repeated/missing hours.
- Unit counts use authoritative selected-state fields, including background occupancy, active/gate state, and ready/available capacity. Pending replay state no longer substitutes initial inventory. Facility queues are scoped by patient facility.
- Map markers, footprints, labels and route links use dataset facility IDs/coordinates; fit bounds includes every located site. The city backdrop and straight route links remain explicitly schematic.
- Data setup now loads full source, respects partial-summary collection counts, exposes all canonical collections, paginates/searches all rows, and provides typed field editing plus advanced JSON. Local typefaces and SIL licenses are bundled.
- Isolated API tests verified draft edit/validation/immutable commit and two CSV collections with renamed fields and explicit ignored columns. A negative test found and drove a repair to prevent invalid parsed imports from committing an unchanged base dataset. Browser editing/layout verification remains separate.
- Local Compose migration, seed, authenticated queue/run/replay/export, PostgreSQL backup and isolated restoration have measured evidence in `evidence/`. OCI deployment is still unverified.
